## Опис проєкту
У цій лабораторній роботі створено консольну програму на C# (.NET SDK) для демонстрації базових принципів ООП. 

Реалізовано клас `Computer`, який описує характеристики комп'ютера (процесор, оперативна пам'ять, накопичувач) за допомогою приватних полів, публічних властивостей, конструктора та методу для запуску тесту продуктивності.

---

## Структура класу `Computer` (Варіант 10)
- **Приватні поля:** `cpu` (модель процесора), `ram` (обсяг оперативки).
- **Публічна властивість:** `Storage` (обсяг диска).
- **Конструктор:** ініціалізує початковий стан комп'ютера під час створення.
- **Метод:** `RunBenchmark()` — моделює запуск тесту продуктивності та виводить результат у консоль.
