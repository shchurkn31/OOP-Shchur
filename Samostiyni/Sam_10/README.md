## Опис проєкту

Консольний проєкт `lab9-self-v10` демонструє власні узагальнені утиліти на числах, словах і товарах.

## Реалізація

`Map` перетворює елементи, `Filter` відбирає потрібні, `MaxBy` повертає елемент з найбільшим ключем, а `ForEach` виконує дію над кожним елементом.

## Приклад

```text
Квадрати: 4, 25, 64, 121
Найдовше слово: папуга
Товари від 1000 грн:
- Монітор
- Клавіатура
```

## Запуск проєкту

У папці `Sam_10` за допомогою .NET 10 SDK.

```bash
dotnet run -c Release
```

## Висновок

- Делегат передає поведінку як параметр. Один метод працює з різними типами колекцій і правилами обробки.
- Лямбда `product => product.Price >= 1000m` описує правило без окремого іменованого методу.
- `Map` і `Filter` працюють ліниво, як LINQ `Select` і `Where`. `MaxBy` виконує один прохід і для порожньої колекції викидає `InvalidOperationException`. `ForEach` відразу виконує дію, як `List<T>.ForEach`, і приймає будь-яку послідовність `IEnumerable<T>`.
