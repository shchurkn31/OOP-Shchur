## Опис проєкту

Консольний проєкт `IndependentWork11` генерує дані з фіксованим seed і виконує чотири аналітичні запити.

## Реалізація

Запити знаходять топ товарів у кожній категорії, дохід по містах, продажі за місяцями та топ клієнтів за сумою великих покупок. Для кожного запиту виводиться час матеріалізації результату. Деталі наведено у [звіті](REPORT.md).

## Приклад

```text
Продажі: 6000, товари: 80, клієнти: 80

Найпопулярніші товари за категоріями (0.801 мс)
Аудіо: Товар 74, 555 од.
Аудіо: Товар 42, 503 од.
Аудіо: Товар 18, 502 од.
…
```

## Запуск проєкту

У папці `Sam_12` за допомогою .NET 10 SDK.

```bash
dotnet run -c Release
```
