## Опис проєкту

Консольний проєкт `IndependentWork7` і тестовий проєкт `IndependentWork7.Tests`.

## Реалізація

`Cache<TKey, TValue>` зберігає значення у `Dictionary`, а порядок додавання — у `Queue`. Коли ємність вичерпано, новий ключ витісняє найстаріший. Оновлення значення зберігає місце ключа в черзі. Для відсутнього ключа `Get` викидає `KeyNotFoundException`.

## Приклад

```text
Ключ 1: Клавіатура
Ключ 1 залишився: False
Кількість: 2
```

## Запуск проєкту

У папці `Sam_8` за допомогою .NET 10 SDK.

```bash
dotnet run -c Release
```

## Тести

```bash
dotnet test IndependentWork7.Tests -c Release
```

Перевіряються додавання, читання, пошук ключа, кількість елементів, витіснення FIFO, відсутній ключ і оновлення наявного ключа.
