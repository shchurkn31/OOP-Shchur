## Опис проєкту

Консольний проєкт `IndependentWork13` моделює перевантажену чергу, повільний експорт і тривалий збій каталогу.

## Реалізація

Черга використовує Retry, експорт — Timeout, а каталог — Circuit Breaker. Усі сценарії виконуються локально через `ResiliencePipeline` і виводять реакцію стратегій. Обґрунтування й фрагменти коду наведено у [звіті](REPORT.md).

## Приклад

```text
1. Надсилання повідомлення до перевантаженої черги
Спроба 1, ID order-42
Повтор 1 через 26 мс: Черга тимчасово переповнена.
Спроба 2, ID order-42
Повтор 2 через 252 мс: Черга тимчасово переповнена.
Спроба 3, ID order-42
Підтверджено order-42

2. Формування звіту з обмеженням часу
Розпочато формування звіту.
Перевищено ліміт 150 мс.
Формування звіту скасовано за тайм-аутом.

3. Читання каталогу під час тривалого збою
Запит 1 передано до каталогу.
Сховище каталогу недоступне.
Запит 2 передано до каталогу.
Захисний вимикач відкрито на 2 с.
Сховище каталогу недоступне.
Запит 3 одразу відхилено захисним вимикачем.
```
