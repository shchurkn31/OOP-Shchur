## Опис проєкту

Консольний проєкт `InvertedIndexDemo` знаходить документи за словами та порівнює два способи пошуку.

## Реалізація

`TextProcessor` нормалізує слова, зберігає токен `C#` і відсіює стоп-слова. `InvertedIndex` підтримує AND через перетин множин та OR через об’єднання. У консолі можна ввести `c# async` для пошуку або `exit` для виходу. Методика та результати наведені у [звіті](REPORT.md).
