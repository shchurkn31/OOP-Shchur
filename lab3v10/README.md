## Опис проєкту
У цій лабораторній роботі реалізовано клас `ImageBuffer`, який моделює роботу з буфером зображення та реалізує інтерфейс `IDisposable` разом із повноцінним патерном Dispose.

Програма демонструє три сценарії керування ресурсами:
1. Автоматичне звільнення через блок `using`.
2. Явний виклик методу `Dispose()`.
3. Неявне звільнення ресурсів фіналізатором (деструктором) через `GC.Collect()`.
